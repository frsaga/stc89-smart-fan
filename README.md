# STC89 Smart Fan

STC89C52RC/Keil C51 coursework: AHT20 temperature and humidity, BMP280 pressure input, software PWM, keys, OLED status and multiple wind modes. Open `oledtest1.uvproj` with Keil C51 and configure your board programmer locally.

This public source snapshot excludes personal reports, local debug options and compiled firmware. The OLED author label has been replaced with a generic product label. Hardware behavior was not retested for publication.
